# Цифровая реальность

Ранний прототип нарративной игры для ПК на Godot 4.6.3.

Открыть `project.godot` в Godot и нажать F6/F5 или выполнить:

```sh
godot --path /workspace/Game
```

Мышь или стрелки и Enter выбирают действия. Прогресс сохраняется в начале каждого дня в `user://progress.json`. «Новая игра» перезаписывает сохранение.

Прототип включает девять дней, ночные занятия, внутренний диалог с четвёртого дня и два финала. Если до девятого дня внутренний диалог не начат, его кнопка исчезает. Для возможности выйти в мир требуется минимум один диалог и не менее 60% конструктивных ответов.

Тексты и геометрический городской фон — временные материалы для проверки механики. Подробная пиксельная графика, звук, настройки, галерея, Windows-сборка и полноценный сценарий пока не реализованы. Изображение-референс не включено в игровые материалы.
